## Resumen

La investigación analiza cómo aplicar los principios de la programación orientada a objetos en n8n y cómo un agente de IA puede orquestar flujos de trabajo. Incluye:

- Verificación técnica de los documentos entregados por el profesor.
- Marco teórico sobre POO, workflows, n8n y agentes de IA.
- Comparación de dos enfoques: la POO como analogía para diseñar workflows y las clases de JavaScript dentro de nodos Code.
- Análisis de eficiencia (velocidad, desarrollo, mantenimiento y costo).
- Casos de negocio posibles y alternativas tecnológicas para una etapa posterior.

## Sobre las facturas de ejemplo

Las empresas, cédulas y datos de las facturas son ficticios y no tienen validez tributaria. Cada factura ilustra una situación distinta: caso normal, dos tarifas de IVA, moneda extranjera, monto alto, total con error de suma e IVA reducido de 4 %.
